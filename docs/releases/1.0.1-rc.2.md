## 本次变化

- 采用 V2 最小生产运行时和 ASAR 打包，不再把完整外置 `node_modules` 复制到安装目录。
- 随包固定携带同一次快照中的 `msfs.exe`、`msfsd.exe`、`SimConnect.dll` 和 EFB Bridge，并校验组件 SHA-256 与协议主版本。
- 应用退出和覆盖安装前优先执行 `msfs daemon stop --json`，旧 CLI 不支持时使用兼容兜底。
- 开发机将 Bridge 的“开发版本”和“应用版本”分开保存，MSFS 根目录始终只启用一个版本。
- 全新安装的凭据输入框为空；已保存的 App ID、API Key 和 Access Token 默认显示密码圆点，点击眼睛可查看真实值。
- 探索规划只依赖其实际需要的 DeepSeek 与 MSFS 配置，不再被 STT/TTS 未配置误判阻塞。

## 升级与回退

安装前先真正退出晓晓飞行导游，建议同时退出 MSFS 2024。覆盖安装会保留 `%APPDATA%\msfs-ai-voice-guide` 中的用户设置和受 Windows 账户保护的凭据。

回退时先退出应用和 MSFS，再运行保留的旧安装包。如果安装器阻止降级，先卸载当前版本但不要删除用户数据，然后安装旧版。开发机只切换 Bridge 时使用 `pnpm msfs:use:dev` 或 `pnpm msfs:use:app`。
