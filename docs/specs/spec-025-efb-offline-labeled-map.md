# Spec-025：EFB 离线地名地图

**状态：** 待实现
**建议优先级：** P1，第三个完成
**目标周期：** 一周内完成可用 MVP；完整详细 POI 不纳入本周

## 目标

在官方 EFB 中增加一个独立的“晓晓飞行导游地图”应用，让用户看到当前飞机位于地球上的具体位置和主要地名。

本需求不修改 MSFS 官方默认卫星地图。

## 用户看到的功能

- 当前飞机位置标记；
- 地图随飞机位置更新；
- 缩放和拖动；
- 全球范围可查看；
- 显示国家、地区、城市和主要机场名称；
- 无网络时仍能打开和使用。

## 不包含

- 修改官方 EFB 卫星图；
- 在线地图服务；
- 谷歌地图或 Bing 地图 API；
- 航路显示和航路编辑；
- 地图搜索；
- 卫星影像；
- POI 故事、自动导游或飞机操作。

## 实现方案

EFB 地图作为当前项目中的第二个 MSFS Community Package，与现有 Native CLI Route Bridge 并列，不与 Bridge 合并。

```text
桌面助手
  ├─ 设置中的 EFB 地图开关
  ├─ 将 EFB 包打进安装包
  └─ 根据 UserCfg.opt 安装/更新/移除 EFB 包

MSFS EFB
  └─ 晓晓飞行导游地图
       ├─ 读取游戏内飞机经纬度
       └─ 读取包内离线地图和地名数据
```

建议使用 MapLibre GL JS 渲染本地矢量地图，使用 PMTiles 保存离线地图数据。地图名称来自随包提供的 OpenStreetMap 数据；飞机当前位置来自 MSFS，不来自 Geo Cloud。

## 安装和开关

- 安装桌面应用时，EFB 包一同进入应用资源；
- 默认建议关闭，用户在设置中主动开启；
- 开启后复制到 MSFS `Community2024`；
- 关闭后只移除本应用自己安装的 EFB 包；
- 开启或关闭后提示重启 MSFS，确保 EFB 重新加载；
- 安装失败时显示原因，不修改官方地图和其他 Community 包。

## 第一周的限制

- 先提供全球主要地名和主要机场名称；
- 不承诺全球所有道路、建筑和小型 POI；
- 地图数据必须随包提供，运行时不向地图服务器请求数据；
- 第一个技术验证先确认 EFB 能读取飞机位置，并能加载本地 PMTiles；
- 如果本地地图文件在 EFB 环境中无法直接加载，改用拆分后的本地矢量瓦片，不增加在线回退。

## 验收标准

- 安装主程序后，EFB 包可以随应用获得，不需要用户单独下载；
- 开启开关并重启 MSFS 后，官方 EFB 应用列表中出现地图应用；
- 地图可以在无网络状态下打开；
- 当前飞机位置能显示并随飞行更新；
- 放大、缩小、拖动可用；
- 在至少多个不同国家/地区验证主要地名显示；
- 关闭开关后，应用只移除自己的 EFB 包；
- 官方默认卫星地图和其他 Community 包不受影响。

## 主要风险

全球离线地图的数据体积和 EFB 对本地地图文件的加载方式需要先做小样本验证。若要求全球所有详细 POI，数据体积和一周交付风险都会明显增加，因此不放入本版。
