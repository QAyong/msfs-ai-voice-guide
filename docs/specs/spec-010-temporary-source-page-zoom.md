# Spec-010：来源网页临时单页缩放

**日期：** 2026-07-25

**状态：** 待实施

## 1. 背景

Spec-009 让来源网页按来源窗的真实可用宽高响应式排版，并保持 Chromium 默认 100% 缩放。用户在阅读较小正文、图表或老旧网页时，仍可能需要临时放大或缩小当前网页。

该能力必须只作用于当前打开的单个来源网页，不能改变应用界面、聊天面板、搜索结果列表、其他来源网页或 Chromium 的全局缩放偏好。

## 2. 决策

在来源窗标题栏、仅当原网页处于加载中、已加载或加载失败状态时，提供紧凑的网页缩放控件：

- “缩小网页”按钮：每次将当前网页缩小 10%。
- 当前缩放百分比：显示当前值；点击可恢复 100%。
- “放大网页”按钮：每次将当前网页放大 10%。

缩放范围为 80% 至 150%，默认 100%。按钮在达到对应边界时禁用，并具有中文无障碍名称、悬停提示和键盘焦点。

缩放仅调用当前 `WebContentsView` 的缩放能力，不创建或重载页面、不修改 URL、User-Agent、设备像素比、触控能力或窗口尺寸。来源窗拉伸时继续提供真实视口；用户手动设置的当前缩放比例不因拉伸而自动改变。

## 3. 生命周期与范围

- 缩放比例只属于当前打开周期内、当前选中的原网页。
- 返回搜索结果、关闭来源窗、重试并创建新的网页视图、选择另一条来源或重新打开来源窗时，比例恢复为 100%。
- 缩放比例不写入窗口状态文件，不跨应用重启、来源窗关闭或不同网页保留。
- 搜索结果预览不显示缩放控件，也不受缩放影响。
- 该功能不提供全局设置、快捷键、站点记忆或浏览器级默认缩放。

## 4. 用户体验

```text
用户在原网页标题栏点击 “+”
        ↓
当前网页从 100% 变为 110%
        ↓
页面在同一 WebContentsView 中重新绘制
        ↓
窗口、URL、滚动位置、表单和网页会话保持不变
```

用户点击当前百分比即可立即恢复 100%，无需寻找额外的“重置”入口。

## 5. 非目标与安全边界

- 不恢复 Spec-009 已移除的 768px/1280px 虚拟布局模式，也不引入设备模拟。
- 不对远程网页注入 CSS、改写 DOM 或强制网页适配窄屏。
- 不改变远程网页的沙箱、权限拒绝、导航白名单、IPC 隔离或系统浏览器打开行为。
- 不缩放本地标题栏、搜索结果、聊天面板或其他应用窗口。

## 6. 验收标准

- [ ] 原网页标题栏显示缩小、当前百分比和放大控件；搜索结果预览不显示。
- [ ] 默认值为 100%，可按 10% 步进在 80% 至 150% 之间调整，并可点击百分比重置。
- [ ] 缩放只影响当前 `WebContentsView`，不改变应用或 Chromium 全局缩放设置。
- [ ] 调整缩放不重载、不重建网页视图，且保持 URL、滚动位置、表单和登录会话。
- [ ] 拉伸来源窗时网页继续使用真实视口，当前用户选择的缩放比例保持不变。
- [ ] 缩放不修改 User-Agent，不启用触控、设备像素比或特定设备模拟。
- [ ] 返回、重试、切换来源或关闭并重新打开来源窗后，缩放恢复 100%。
- [ ] 缩放控件具有中文无障碍名称、提示、键盘焦点和边界禁用状态。
- [ ] 现有来源加载、错误恢复、导航安全、自由移动和响应式布局测试继续通过。
